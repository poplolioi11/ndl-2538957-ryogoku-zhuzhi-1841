玉岡道人《両國竹枝》，天保十二年跋（1841）刊本，國立國會圖書館藏，索書號842-68。整理署名：**poplolioi11／一卦 yigua.art**。版本日期：2026-10-24（Asia/Taipei）。

本版整合全冊初錄、獨立讀圖、逐差及高風險處回圖裁定的五份固定成果。主控已有限度採納：核對輸入與對齊覆蓋，回看關鍵圖證；**主控沒有親自逐字重讀所有字，本版仍是保留未解的AI複核版，並非專家定本**。本版已通過主控的格式、來源指紋與公開內容檢查；v0.1.0 初錄固定版本保持原樣。

原PDF全部18/18影像幀均在來源序列內，含封面、空白、題頁、序、題詩、圖中文字、正文、原註、讀音／返點與跋。18幀呈現34個書面，含封面與空白；幀號不是原葉碼。已嘗試整個來源，不代表每個字都已辨明。本版有641個分層單位、3057個文字碼點（含占位）、263個一字位置「□」、312個疑讀位置，另有74個未知字數區域。目錄稱漢詩50首；未依目錄補造分首標題或句讀。

## 檔案與限制

本包採平面檔名：`book.json`、`book.txt`、`book.tei.xml`、`collation.json`，另附來源、引用、權利、驗證與修訂說明。`book.json`保存幀、面、欄、層、疑字、候選、缺口與母欄／字位；欄位無可靠值時為null。候選不是採定字。原字串不作NFC、簡繁或異體正規化，不加現代句讀，不從記憶或現代整理文字補字。

第6–8幀的19列讀點依170個原事件的**物理事件索引序**串接，並保存各事件的母欄、字位、位置及串接範圍；這不是訓讀語序，亦非返讀語法分析。12個明示未定的錨點保留null及來源候選，不能視為已驗證字位。`bbox`是實見欄／區域定位，原native xywh轉成3600×3347底圖xyxy；沒有可靠測量者為null，不捏造逐字框。

TXT每行為`[單位ID]`、TAB、字串。TEI P5每幀有`pb`、每單位有`ab`。一字不可辨「□」對應quantity=1；未知字數區域另用extent=unknown。TXT行尾`⟦gap:unknown⟧`只報告該單位有未知缺口，**不表示缺口在行尾，也不表示一字**。末跋三個原「□」只是未知長度區的定位符，已從字符正文移至JSON `gaps.source_gap_anchor`，保留原碼點位置與輸出邊界，再附未知缺口標記。`collation.json`提供見證讀法、原裁定提議、現輸出、筆畫理由與圖證指紋；不重寫舊提議為專家採定。

第4及第6幀淡印的獨立補遺產生在主盲稿之後；本版明記補足的範圍，不倒稱早先已盲讀。印文／正面鈐印或透印仍未定者保留。現代尺規、攝影標籤及可辨紙背透字不併入古籍正文。

初錄第4幀日期、次欄及署名印的bbox有誤，複核已回原圖重新定位；`collation.json`逐項保存舊框與新框。v0.1.0固定資料保留作初錄見證，**其這些舊bbox不可當作可靠定位**，本版未沿用舊框。

## 驗證命令

在包目錄內執行以下三種基本命令；本版均已實測：

```sh
python3 verify.py . --self-test
python3 verify.py . --whitelist PUBLIC-FILES.txt --self-test
python3 verify.py . --whitelist PUBLIC-FILES.txt --self-test --tei-schema /path/tei_all-4.12.0.rng --cff-schema /path/cff-1.2.0-schema.json
```
